# The Reporting Line

Georgia Code of Ethics scenarios for preservice teachers. Students take one of two desks:

- **Principal's desk** (9 incidents) involving practicing teachers and coaches
- **SOE professor's desk** (7 incidents) involving teacher candidates who hold Georgia Pre-Service certificates

Every incident is told as if it's no big deal. For each one, students decide:
1. Does it need to be reported? (yes / no)
2. Which Code of Ethics standard is it? (Standards 1–10, or "not a violation")
3. Where does it go? (DFCS within 24 hours, a GaPSC ethics report, the placement school and university office, or handle locally)
4. Why, in their own words

They lock in their answers (scored out of 3) and then see the ruling, who reports and when, a takeaway for their own practice, and real cases with the consequences, each linked to its source. All 10 standards are covered, and 3 incidents are deliberately *not* reportable so students learn not to over-report.

## How to add it to the repo
1. In `Education-Scenarios`, create a folder named `reporting-line`.
2. Upload `index.html` and this README into it and commit.
3. Link it from the hub page, e.g. `<a href="reporting-line/">The Reporting Line: Report It or Not?</a>`

## Notes for instructors
- Student work is saved only in each student's own browser. They submit with **Copy my responses** and paste into D2L.
- Locked answers can't be changed except with **Start over**.
- To edit an incident, find the `const S = [` array in `index.html`.
- Real cases are summarized from published news, GaPSC guidance, and state rules. Individuals are not named; charges are labeled as charges.
- Rulings model common application of the Code; they are not legal advice. When in doubt, contact the GaPSC Ethics Division.
